📖 「직원」 인권침해대응지침 — 면담 확인 내용
1. 인권침해 유형 (직원이 알아야 할 3가지)
유형구체적 사례
폭언"가만 두지 않겠다", 모욕적 욕설, 협박 등 언어적 폭력
폭행때리거나 위협, 물건 투척, 꼬집기·머리카락 잡아당기기
성희롱·성추행음란 농담, 신체 부위 접촉, 성기 노출 등
2. 폭언·폭행·성희롱 발생 시 대응방법 (3단계)
단계내용
1단계
자제요청·즉시경고		폭언 중단 요청 → "이런 행동은 문제 해결에 도움이 되지 않는다" 안내 → 대화 유도
2단계
녹음 사전 고지		폭언 지속 시 사전 고지 후 녹음·녹화 실시
3단계
응대종료·경찰신고		관리자 도움 요청 → 서비스 불가 설명 → 현장 이탈 → 기관 구두보고 → 6하원칙 문서 작성 → 필요 시 법적대응
※ 위기·응급 상황 시 1단계 생략 즉시 3단계
3. 급여 외 행위 제공 요구 시 대응방법
  • 수급자 외 가족만을 위한 서비스 제공은 거절할 수 있음을 안내
  • 거절 후에도 반복 요구 시 기관에 즉시 보고
  • 기관은 수급자(보호자)에게 급여 외 행위 불가 사유를 공식 안내
4. 인권침해 상황 발생 시 기관의 조치사항
  • 직원으로부터 피해 접수 (구두 또는 고충처리함)
  • 사실 확인 후 6하원칙에 따라 문서 기록
  • 수급자·가족에게 재발 방지 요청 (서면 또는 구두)
  • 필요 시 계약 해지, 경찰 신고, 법적 대응 검토
